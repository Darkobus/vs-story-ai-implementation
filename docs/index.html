Vintage Story · AI assistant · RAG

What this project is and how it works

A guide to the in-game AI assistant for a Vintage Story server: the vector database and cosine distance, how the bot runs, and what is still on the roadmap.

Python ChromaDB Ollama (bge-m3) Gemini RAG RCON Docker

? In one paragraph

This is an AI chat assistant for a Vintage Story game server. It follows the players' chat in the logs of the game server (which runs in Docker). When someone writes AI <question>, it looks up matching game knowledge in a vector database (recipes, items, blocks, wiki pages) and generates an answer with a language model (Gemini, or a local Ollama model). The answer goes back to the chat over RCON, in Polish. The bot can also run a couple of harmless commands (time, weather) and reacts to world events.

Persona: the original bot played a “dark god”. It is now a plain, helpful assistant whose answers are grounded in the knowledge base. Why, and what the prompts look like: Persona.
